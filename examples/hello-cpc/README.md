# Hello CPC

Petit exemple de source de référence pour le futur harness J0 : mode 1, palette, texte, rectangle, son et attente clavier. Le manifeste respecte le contrat version 1. Le listing utilise uniquement des caractères ASCII pour isoler le premier essai des problèmes d'encodage.

Ce dossier est un **exemple de projet**, pas une application lançable depuis ce dépôt et pas un DSK déjà construit. Son exécution réelle reste à vérifier sur le firmware choisi. Une fois la chaîne implémentée, le disque attendu contient `MAIN.BAS` et se lance par `RUN"MAIN.BAS"`.

Le projet n'a ni ROM ni clé IA. Le [rapport illustratif](../build-report.json) n'affirme aucun build effectué. La [proposition IA illustrée](../ai-proposal.json) remplace ce listing sur la base de son empreinte courante ; elle n'est pas appliquée à l'exemple.
